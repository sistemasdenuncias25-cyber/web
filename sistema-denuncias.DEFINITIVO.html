Módulos Principales

Nuestro sistema integra todas las funcionalidades necesarias para un proceso de denuncia eficiente y transparente

Registro de Usuarios

Formularios diferenciados para ciudadanos y funcionarios con validación de identidad y roles específicos.

Registro de Denuncias

Formulario intuitivo para registrar denuncias con soporte para adjuntar evidencias y documentación.

Seguimiento de Casos

Interfaz para consultar el estado actual de cada caso y ver el historial completo de actualizaciones.

Transparencia

Reportes y gráficos abiertos sobre estadísticas de denuncias, tiempos de respuesta y resolución.

Panel de Administración

Herramientas para gestionar usuarios, casos, instituciones y generar reportes estadísticos.

Información ODS 16

Recursos educativos sobre el Objetivo de Desarrollo Sostenible 16 y su importancia para la sociedad.
